# Windows 与 macOS 功能核对

核对日期：2026-10-09。参照 [macOS main 的 e207d11](https://github.com/laogou717/dogsc/tree/e207d11b111c5e58152238fb64115b2009850547)。本地 Swift 源码停在 2026-10-05；另读取了后续变更列表与相关补丁。

本轮已实施下列补齐。结论来自源码、Windows 桌面交互和真实 ffmpeg 导出，没有在 Mac 设备上运行并排测试；共用几何参数不代表两种渲染器逐像素相同。

## 本轮已补齐

| 能力 | 当前实现与验证范围 |
|---|---|
| Mac 导入保留声音 | 转码前从屏幕素材抽取系统音频，保存独立音轨，导出仍保留。无 ffmpeg 时明确说明未分离声音 |
| Mac 指针与标记 | 读取 JSONL 指针及点击；迁移录制标记、摄像头 / 麦克风起始偏移、导出分辨率 / 帧率；edited 序列保留裁短范围并探测素材尺寸 |
| 光标播放与导出 | 同一采样器，连续采样点插值、长时间静止不提前移动，按导出帧率生成小尺寸透明视频；不再用每段 48 点的阶梯位置表达式；跟随裁切、缩放、圆角和透视，大小随缩放变化 |
| 光标详细控制 | 大小、静止隐藏延迟、点击颜色 / 大小 / 不透明度、独立毫秒校准；隐藏光标同时隐藏点击反馈 |
| 空间裁切和比例 | 左 / 上 / 保留宽 / 高及重置；增加 3:4、2.39:1、1:2.39 和自定义宽高比，接通保存、撤销、预览和导出 |
| 摄像头显示和同步 | 独立隐藏、镜像、全片时间校准；Mac 媒体起始偏移参与预览和导出；片段切换正确设置输出时间戳，不把尾帧永久覆盖到后续片段 |
| 倾斜几何 | WPF 3D 网格和 ffmpeg 使用同一相机投影及四角坐标；成片增加四边形透明遮罩，防止透视外侧被拉伸填满；点击焦点做逆投影 |
| 连续点击运镜 | 1.4 秒内的操作合成镜头，近处点击稳定构图，远处目标连续平移；操作活动延长保持，静止采样不会延长；相邻手动 / 自动缩放直接衔接，重新生成保留手动镜头；按裁切后的点击位置和变速 / 校准后的时钟求值 |
| 缩放过渡参数 | 独立进入 / 退出及保持，线性 / 五次平滑 / 弹簧曲线，弹簧质量 / 刚度 / 阻尼；按 Mac 的归一化阻尼弹簧响应计算，预览 / 光标 / 导出共用轨迹。短片段按比例缩短过渡，参数复制和撤销保留 |
| 暂停编辑缩放 | 选中缩放段时直接预览目标倍率与焦点，播放时恢复按时间求值 |
| 用户场景预设 | 保存、更新、应用、删除、新录制默认；图片复制到预设目录，应用时再复制进当前项目，保留当前素材、剪辑及声音 |
| 多片段装饰 | 独立效果页，多张贴图 / 多个柔化和聚光；选择、删除、移动、裁短、吸附、重叠分行与滚动；保存、撤销、删剪和变速同步；独立剪贴板支持完整副本和只粘属性，跨窗口贴图会复制媒体 |
| 区域跟随与过渡 | 新柔化 / 聚光使用源画面坐标，跟随裁切、缩放、圆角与透视；旧画布坐标保留并可切换。区域宽高、位置、圆角、强度 / 外围压暗、无 / 线性 / 平滑过渡与独立淡入淡出；柔化默认无过渡。平滑采用 Mac 五次曲线及 min 组合 |
| 区域直接编辑 | 预览框选、反向框选、移动、边角缩放、重画与取消；框选时暂时隐藏区域效果，方便看清目标；小选区手柄放在外围，中心可移动；像素输入及 1 / 10 像素方向键微调，每次拖动可单独撤销；暂停完整显示所选效果并标明编辑预览，播放恢复时间线；矢量预览遮罩减少拖动时的图片分配 |
| 多效果迁移 | 迁移所有贴图的时间、位置、宽度、透明度、旋转和图层顺序，以及所有柔化 / 聚光的区域、圆角、强度和过渡；复制所有引用图片。同名图片导入使用独立文件，保持显示名称 |
| 高倍速 | 0.5–100× 编辑与导出，音频用多级 atempo；100× 的时长与滤镜有回归测试，尚未完成各档位实时预览性能测试 |
| 导出流程 | 项目保存分辨率 / 帧率；准备和渲染阶段、已用时间、剩余时间估计；修状态文字裁切；取消或失败保留旧同名成片，成功后才替换 |

实际成片检查还修复了柔化遮罩让整幅视频变成灰度的问题。自检包含颜色像素、透视边缘和取消时旧文件保留的检查，防止只检查“导出成功”而漏掉画面错误。

## 仍有差别

| 功能 | Mac 行为 | Windows 尚缺或不同之处 |
|---|---|---|
| 窗口录制 | 原生单窗口采集、窗口选择和跟随 | 主要按窗口矩形录桌面，遮挡与移动行为不同 |
| 录制目标与参数 | 最近目标、更多目标切换、详细质量 / 光标 / 设备设置 | 目前只有现有显示器、区域、窗口、视频设备入口及基础选项 |
| 录制恢复 | 恢复日志、发现中断录制并恢复项目 | 已移植恢复流程：启动时扫描项目目录，只有 media/ 没有 project.json 的半成品按 <token>.mp4 / -camera / -mic / -system 命名归组逐 take 探测时长重建项目文件并进最近项目列表；仍缺 Mac 的恢复日志（录制中实时写元数据，靠目录扫描代替） |
| 连续自动运镜 | 点击分组、活动保持、连续衔接、弹簧参数 | 已支持连续操作分组、附近点击稳定构图、跨区域平移、活动保持与弹簧参数；仍缺 Mac 连续指针控制器、速度限制 / 边界跟随策略，未做真实 Mac 并排观感测试 |
| 缩放曲线 | 独立进入 / 保持 / 退出、动画曲线 | 已支持独立进入 / 退出、其余时段保持，以及线性 / 五次平滑 / 弹簧曲线；尚缺自由贝塞尔、二次 / 三次预设及 Mac 曲线和时长的完整迁移 |
| 屏幕 / 摄像头运动 | 独立效果片段、三轴旋转、联动和曲线 | 已移植并接通导出：TransitionTiming（进入/回落窗口+进度偏移+六种缓动+自定义贝塞尔+弹簧）、屏幕轨道（rect 空间插值+投影锚点+三轴旋转，导出经 15Hz 常量角点 perspective 分段逼近逐帧）、摄像头轨道（形状↔全屏连续解析、隐藏目标原位淡出，导出经逐帧 scale+overlay+geq 表达式）；Mac 项目导入映射 screenMotionClips/cameraMotionClips。近似：ffmpeg 9.0.2 perspective 不支持逐帧角点表达式故分段常量（15Hz）；摄像头圆角遮罩为静态形状不随布局插值变形 |
| 摄像头构图 | 方 / 横 / 竖 / 原比例、内容缩放与位置、分段同步点 | 形状比例、内部缩放 / 位置、镜像构图及直接摆放已接通；仍缺分段同步锚点、独立运动轨道及缩放联动 |
| 贴图外观和动画 | 圆角、边框、阴影、背景虚化、弹出 / 位移动画、独立曲线、隐藏屏幕 / 摄像头 | 已移植：15 个字段与默认值同步；圆角/描边/投影烘焙为一张留边 PNG 后叠加；11 种进入预设 + 自动互补退出 + smooth/swift/gentle 曲线与分段时长；相邻贴图交接 join 与背景桥；压屏幕 / 压摄像头、屏幕 / 摄像头虚化走预渲染 mask 视频逐帧合并；ffmpeg 9.0.2 的 maskedmerge 与 qtrle 小尺寸多帧编码有 bug——合并统一改用 alphamerge+overlay、压屏幕改烘进动画 overlay 帧、背景 mask 改用 raw bgra 流；另有 label 二次引用陷阱——placed 流被挖洞 alpha 与合成 overlay 各引一次时，第二次引用被静默改链到未命名输入流，已用 split 出两份修复（影响此前批次的合成正确性） |
| 光标样式和运动 | 样式库、运动平滑、弹簧、运动倾斜、不同点击效果 | 仍为箭头 / 圆点和圆环反馈，尚无样式库及运动参数 |
| 背景与样机 | 视频 / 动态背景、浏览器 / 窗口 / 手机外框、边框 | 已移植：视频壁纸（-stream_loop 循环 + cover 裁切 + 模糊）；屏幕外框 windowLight/Dark、browserLight/Dark（顶栏+红绿灯+标题/地址栏药丸，46pt 规格）、devicePhone/Tablet（四边 bezel + 圆角 + home 指示条，方向按画面宽高比选），烘成画布大小 PNG 叠在卡片上、随屏幕运动透视一起变；外框启用时卡片圆角改用内容圆角贴合外框轮廓。Mac 项目导入映射 screenFrame* 与 projectVideo/systemVideo 壁纸。pattern 矢量网格背景（obsidianGrid / engineeringWhiteGrid / midnightDots / architecturalDots / isometricMesh 全部 5 个：底色 + 网格 / 点阵 / 斜交网格层烘 PNG 叠加）与 dynamicFlow 动态背景（cyberDriftGrid 斜漂网格+摆动辉光、starfieldDots 漂移点阵、auroraFluid 蓝色渐变+三块高斯光斑相位漂移：每层烘带透明通道 PNG 用 overlay eval=frame 逐帧位移表达式）已移植；patternScale / patternOpacity 字段对齐（0.4..6 / 0..1）。Mac 项目导入映射 pattern / dynamicFlow 的 patternPreset / dynamicFlowPreset（中文 rawValue→case id）与两个强度字段；程序生成背景不套用图片壁纸的模糊 |
| 时间线深度 | 剪切缺口恢复、更多轨道及显示控制 | 已移植剪切缺口恢复（交界处/片头/片尾三入口，插回被裁源段并把后续时间轴效果整体移位、跨插入点区间拉长，工具条「还原」按钮按选中片段启停、可撤销）；仍缺更多轨道及显示控制 |
| 效果复制 | 各效果轨道独立复制完整片段或只粘属性 | 缩放和装饰已支持；屏幕 / 摄像头独立运动尚未实现，仍无法复制那些轨道 |
| 素材交换 | 导出屏幕 / 摄像头 / 麦克风源文件、替换摄像头 | 已移植替换摄像头：Core 层 MediaSwap 保留片段/效果/偏移换源文件，编辑器「画中画」面板有「替换摄像头素材」按钮（拷进项目 media/ 后换引用）；仍缺导出源文件清单与替换屏幕/麦克风入口 |
| 预览质量与渲染 | 质量档位、共享渲染链路 | 已移植质量档位：设置页「清晰预览（流畅）/完整分辨率」，低清档为屏幕和摄像头素材生成四分之一像素数代理（previews/*.q.mp4，按源文件 mtime 复用、转码失败回退原片）；WPF 和 ffmpeg 的模糊、阴影、抗锯齿仍有视觉差别 |
| Mac 项目兼容 | 原生保存全部轨道 | 仍是单向转换；未迁移复杂运动、贴图高级外观 / 运动、媒体 sourceTimeScale / 分段同步锚点及完整开场，导入时说明略过项 |
| iOS 设备 | 原生发现 / 录制 | DirectShow 采集卡不等于原生 iOS 采集 |
| 辅助窗口排除 | 新版只从自身录制排除，其他录屏工具可拍到 | Windows 使用系统捕获排除标记，排除范围更广 |

## 验证

- .NET 构建：零警告、零错误。
- 核心测试：126 项通过，包含连续光标、源时钟校准、裁切边界、时段删剪 / 变速、预设隔离、四角投影与逆投影、高倍速音频，以及区域反向框选、越界移动、保持对角的缩放、裁切 / 缩放 / 透视逆映射和 4K 窄小文字选区。
- ffmpeg 9.0.2 自检：基础导出；裁切 / 光标 / 点击 / 镜像 / 同步 / 音频组合；多贴图 / 旋转 / 图层顺序 / 多柔化 / 聚光时段和独立过渡；按像素检查聚光的裁切、缩放与结束恢复；颜色 / 透视边缘 / 取消保留旧文件；模拟带音频 MOV 的 Mac 项目导入再导出；屏幕采集。
- Windows 桌面：透视预览、暂停缩放目标、多效果分行与纵向滚动、第二张贴图独立裁短保存、复制副本、只粘属性保留时段、撤销重做、场景预设保存 / 应用 / 删除与图片保留、导出窗口和实际成片检查。
- 区域易用性实操：在客户表格上框选第二行邮箱柔化、框选金额聚光，拖到下一行、抓边角缩放、撤销、像素输入、Shift 方向键微调、越界拖动及取消重画。复现并修复整张画面误拖和小选区中心被手柄抢占的问题；在裁切、1.35 倍缩放和双轴透视组合下再次移动及反向重画，选区仍覆盖对应字段。临时测试项目结束即清理。
- 收尾实操：效果列表用方向键和 Enter 正常选择，不误移区域；画布 / 原画面坐标切换后仍覆盖同一金额；框选期间原先被柔化的邮箱清晰可见，完成后恢复所有区域效果；撤销新增只移除新区域，重做后重新选中并可继续编辑。
- 贴图与摄像头易用性实操：新增第三张贴图、中心拖动、固定对角等比例缩放、旋转手柄、Tab 切换选中、边缘约束、像素数值及 Shift 方向键微调；摄像头外框拖动 / 缩放，横 / 竖 / 原比例切换，2 倍内部放大、构图拖动及一次撤销。复现并修复 26 px 宽小贴图中心被缩放手柄抢占的问题，点选摄像头直接显示对应设置。经应用导出 1280×720、8 秒视频，抽帧核对贴图位置、旋转、图层及摄像头构图，测试项目和成片结束即清理。
- 摄像头成片像素检查：横向 / 原比例蒙版、内容缩放、镜像后的视觉焦点与蒙版外原画面保持。
- 连续运镜实操：客户管理画面生成两个操作镜头，重复生成不叠加；实播、按点击时刻定位、自动焦点转手动微调及一次撤销、展开过渡与弹簧参数。修复快速反向点击时下一目标提前抢占镜头、当前按钮移出画面，以及焦点控件显示起始值导致手动调整跳回起点的问题。
- 连续运镜成片：红蓝色块素材按 11 个时刻抽帧，实际边界与预览运动计算误差不超过 4 px；包含快速换目标、反向移动、退出恢复。实际捕获并修复非整帧缩放切片造成约一帧的运动延迟；缩放改为素材片段内连续求值，小素材两倍采样减少整数裁切跳动。
- 真实 Mac 设备生成的复杂多轨项目尚未端到端验证。此次 MOV / JSONL 迁移验证使用根据 Mac 格式生成的样例。

Windows 的工具条大小、收起展开、四边吸附与过渡保留。按用户要求删除的 Mac 更新提示不恢复，Mac 下载入口不计为待补功能。

主要源码：`Sources/RecorderCore/ProjectModel.swift`、`ProjectTimeline.swift`、`FrameScene.swift`、`OverlayTimeline.swift`、`AutoZoomPlanner.swift`，以及 Windows 的 `ProjectDocument.cs`、`MacProjectImporter.cs`、`CursorTimeline.cs`、`ZoomMotion.cs`、`PerspectiveGeometry.cs`、`EffectTiming.cs`、`ExportGraph.cs`、`EditorParityControls.cs`、`EditorDecorations.cs`、`RegionPreview.cs` 和 `Services/SelfTest.cs`。
