## 2026-10-11：聚焦链路

- 新增缩放片段的径向聚焦：随运镜、随鼠标、固定源画面位置；清晰范围、模糊程度、羽化、暗角。
- 屏幕3D使用同一聚焦模型，保留旧项目线性清晰带；使用原版清晰半径、羽化与按输出短边缩放的模糊半径。
- 预览和导出共用源坐标、裁切、缩放、投影遮罩计算。遮罩按输出帧率生成；当时屏幕视频几何仍是原有15Hz分段；下方的屏幕逐帧导出更新已替换该路径，真实Mac并排观感仍未验证。
- 聚焦作用于屏幕与背景，摄像头和贴图在之后合成；缩放/3D重叠时只启用一个聚焦，避免重复模糊。
- 参数参与保存、撤销快照、缩放复制/只粘属性、3D创建默认值、Mac项目导入。
- 核心测试264项通过，包含新增8项聚焦检查；主程序及独立WPF检查程序构建零警告、零错误。
- 实际成片：径向中心/外围细节55.1/0.9；暗角、摄像头/贴图排除、退出恢复、仅暗角不模糊及WPF预览通过。原有线性清晰带中心/外围62.8/3.2，描边、3D倾斜、3D+缩放与片段音量/M4A成片检查通过。数值来自320×180虚构素材，不是跨设备质量承诺。
- 测试素材、成片、遮罩和辅助图片结束即清理；未改动用户项目或提交Swift参考代码。

## 2026-10-11：原生窗口录制与连续跟随

- 窗口录制改用 Windows Graphics Capture，按 HWND 获取画面，移动和遮挡不再改变录制来源；尺寸变化完整缩放到该片段的固定画布。暂停恢复使用新尺寸。
- 最小化或关闭时保留最后画面，并写入录制标记；鼠标按当前窗口物理坐标和留白位置映射。鼠标移出目标、被其他窗口遮挡或系统隐藏时不记录其他窗口操作，并隐藏回放光标。
- 编码器启动失败时释放采集、音频和编码器资源；30/60fps 取样代替旧的80ms光标轮询。
- 用临时虚构 HWND 实测：400×224 录制、遮挡、移动、缩放、最小化/关闭保留帧、鼠标坐标/可见性、暂停恢复450×250、标记保留和失败启动清理。结束恢复鼠标并删除全部临时文件。
- 连续跟随移植自上游 e207d11 的 ProjectPointerTrack：120Hz 持续弹簧、中央稳定区域、越界只更新相应轴；入口按保留素材的指针/点击确定，裁切、变速、校准及跨素材切口独立求值。保留旧的“点击分组”选项。
- 预览、聚焦和成片共用 ZoomMotion。导出按输出帧率写入实际轨迹，以平衡表达式树避免长轨迹超出 FFmpeg 嵌套深度；实际30/60fps灰度坐标素材验证稳定区、越界跟随和反向运动构图。没有在Mac设备上进行并排观感测试。
- Mac导入不再丢弃指针平滑档位及指针弹簧参数；旧全局屏幕关键帧风格仍明确列为略过项。
- 最新核心测试271项通过，主程序和WPF检查程序构建零警告、零错误。原生窗口需要Windows 10 2004及更新系统。

```powershell
dotnet run --project windows/tests/DogSC.UiChecks -- --native-window
dotnet run --project windows/tests/DogSC.UiChecks -- --pointer-follow
```

## 2026-10-11：录制目标、参数与实时触点

- 菜单支持最近五个录制目标、录制中切换目标与刷新设备；最近窗口按当前标题及进程重新解析，不持久化HWND。已关闭窗口、已断开设备和失效区域明确提示重新选择。
- 目标切换按独立片段保存，来源名称写入素材与恢复日志；失败目标不会回退录制桌面。切换失败保留已有片段并暂停，可恢复旧目标；暂停时换目标维持暂停状态。
- 默认录制参数新增体积优先／标准／高清（CRF24/20/18）、鼠标轨迹开关与实时触点开关；摄像头、麦克风、系统声音和30/60fps选项继续保留。画质是录制编码质量，与原有预览代理画质分别设置。
- 实时点击提示使用独立置顶透明窗口，不激活、穿透鼠标，并申请系统采集排除。暂停、停止和关闭时清理；短暂提示结束自动隐藏。左右键事件监听保留视频采样间隔中的快速点击，失败时使用原有取样路径并记日志。
- 实际检查通过：提示窗口确实绘出蓝色，真实桌面采集六帧均保持下方虚构青色画面；快速左右键各记录一次，点击穿透、提示消失、关闭后通知安全。
- 实际检查通过：两个虚构窗口的运行中切换、失败目标保留、暂停时换目标和恢复，三段各自保留正确像素、来源名称和标记；关闭鼠标轨迹后数据为空；最近目标设置保存／重载及失效设备处理。所有测试文件即时清理。

## 2026-10-11：屏幕逐帧导出

- 屏幕3D、三轴旋转、锚点、缩放、位移及原生开场改为输出帧率的共享姿态；旧zoom/lift开场缩放也不再使用15Hz常量分段。
- 实测本机FFmpeg支持perspective的eval=frame，时间使用一基帧计数in减一。以平衡表达式树保留每个输出帧的坐标，在线合并同一直线上的点，避免静止长片段产生大量重复表达式。
- 为投影增加透明源边缘，防止缩小时源边界颜色铺满空白区域；修复旧背景反向alpha叠加导致淡入透明度重复相乘、画面比预览暗的问题。RGB合成分支与alpha分支明确格式，避免滤镜协商丢失透明平面或改变遮罩范围。
- 实际成片检查：30/60fps下560个可见标记帧的位置最大偏差0.72像素，覆盖3D进入/保持/回落、叠加light3D原生开场、zoom/lift开场缩放；总帧数、淡入亮度和零留白缩小时的透明边缘通过。素材为320×180虚构画面；不能据此承诺4K性能或真实Mac观感完全一致。
- 原有径向/线性聚焦、边框、静态倾斜、3D+缩放和声音导出实际回归通过。摄像头仍需改为逐帧几何与形状遮罩；旧slide/lift位移使用整数裁切，亚像素位移继续细化。
